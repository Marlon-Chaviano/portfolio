## Escribir un artículo

Cada artículo es un archivo MDX junto a este. Funciona Markdown normal, y también componentes de React cuando un párrafo no alcanza.

1. Crea `mi-articulo.es.mdx` (y `mi-articulo.en.mdx` si lo quieres en los dos idiomas).
2. Añade su título, fecha y resumen en `posts.ts`.
3. Haz push. La página se genera en el build.

## Qué incluye

Código en línea como `pnpm dev`, y bloques:

```ts
export function greet(name: string) {
  return `Hola, ${name}`;
}
```

> Las citas van en grande, para la frase con la que el lector debería quedarse.

- Listas
- **Negrita** y *cursiva*
- [Enlaces](https://nextjs.org/docs/app/guides/mdx)
