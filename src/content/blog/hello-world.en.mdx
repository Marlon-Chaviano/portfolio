## Writing a post

Each post is an MDX file next to this one. Plain Markdown works, and so do React components when a paragraph is not enough.

1. Create `my-post.en.mdx` (and `my-post.es.mdx` if you want it in both languages).
2. Add its title, date and summary to `posts.ts`.
3. Push. The page is generated at build time.

## What you get

Inline code like `pnpm dev`, and blocks:

```ts
export function greet(name: string) {
  return `Hello, ${name}`;
}
```

> Quotes are set large, for the one sentence a reader should leave with.

- Lists
- **Bold** and *italic*
- [Links](https://nextjs.org/docs/app/guides/mdx)
